Install RuneScope

Works on Windows, Mac, Linux, Android and iOS. No installer, no "unknown publisher" warning, updates itself the moment this site does.

On an iPhone or iPad: open this page in Safari, tap Share, then Add to Home Screen.

This browser doesn't offer a one-tap install here -- Chrome, Edge and most Chromium-based browsers do; Firefox's desktop browser doesn't offer it at all. Either way, keeping this as a regular tab works exactly the same. Nothing on this site needs it installed.

What "installed" gets you

Its own window and taskbar/dock icon, no browser chrome around it, and it opens straight to your dashboard.

Do I need to install it?

No. Everything on this site works in a plain browser tab, on any device, with nothing installed. Installing just makes it feel like its own app.

Set up the Windows app

  1. Install it and open it. It works fine on its own from here, with a local journal on your PC and nothing connected yet.
  2. Get a desktop token. On your profile, under Desktop app, name it after this PC and press Get a token. Copy it now, it's only shown once.
  3. Paste it in under Settings → Website in the app. Leave the website address alone unless you're running your own copy of RuneScope.
  4. That's it. A trade recorded in either place reaches the other within a minute, and deleting one removes it from both. Your Dashboard here shows whether the app is currently connected.

This token is separate from the RuneLite plugin's pairing token. The plugin feeds the sync service, while this one proves the app belongs to your account. Installing the plugin is a different job entirely.

What the Windows app does differently

  • Runs in its own window even when this site is installed, so it sits beside the game instead of behind a browser tab.
  • Keeps its journal in a file on your PC, mirrored here while it's connected.
  • Works fully offline with whatever prices it last fetched, where installing this site currently only caches its own shell.
