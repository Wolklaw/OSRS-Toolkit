Windows 10 or 11, 64-bit. The portable zip runs from a folder without installing anything. All versions and release notes.

Windows shows a "don't run this" prompt for apps it hasn't seen before — choose More info, then Run anyway. The build isn't signed yet.

Do I need it?

No. Everything on this site works in the browser, on any device, with nothing installed. The desktop app is for people who would rather have a window beside the game than a tab.

One journal, both places

Paste a desktop token from your profile and the two stay level: a trade recorded in either shows up in the other within a minute. How to connect it.

Set it up

  1. Install it and open it. It works on its own from here — a local journal on your PC, nothing connected.
  2. Get a desktop token. On your profile, under Desktop app, name it after this PC and press Get a token. Copy it — it is shown once.
  3. Paste it in under Settings → Website in the app. Leave the website address alone unless you run your own copy of RuneScope.
  4. That is it. A trade recorded in either place reaches the other within a minute, and deleting one removes it from both. Your Dashboard here shows whether the app is currently connected.

This token is separate from the RuneLite plugin's pairing token — the plugin feeds the sync service, this proves the app to your account. Installing the plugin is a different job.

What it does differently

  • Runs in its own window, so it sits beside the game rather than behind a browser tab.
  • Keeps its journal in a file on your PC, mirrored here while it is connected.
  • Works offline with the prices it last fetched.
  • Same calculations as this site — the two share the code that does the maths.
