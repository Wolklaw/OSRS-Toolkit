Not on the Plugin Hub yet.

The submission is in review, and reviews take a while, so this could be the install method for a good while yet. Until it lands, you build the plugin yourself. It takes about ten minutes: a free Java install, and opening a terminal window once. Don't worry if you've never done that, every step below walks you through it. Everything on this site still works without the plugin in the meantime, it just saves you some typing.

Build it yourself

  1. Install Java 11 or newer. RuneLite comes with its own Java built in, so you almost certainly don't have this yet. Grab Temurin, it's free, open source, and unlike java.com's download it can actually build software, not just run it. Default install options are fine, just click through.
    2. {# Every link here is built from PLUGIN_BRANCH rather than written out, so the ZIP, the clone and the folder name cannot drift apart -- see the note beside that constant for the time they did, and what it cost. #}
  2. Download the plugin. Grab the ZIP, then right-click it and choose Extract All (on macOS, just double-click it). You'll end up with a folder called osrs-toolkit-runelite-{{ plugin_branch }}. If you'd rather use git:
    git clone {{ plugin_repo_url }}.git

    Browse the source first if you'd like to see what you're building before you build it.

  3. Open a terminal in that folder. This sounds scarier than it is. Open the folder in File Explorer, click once in the empty address bar at the top (it'll highlight blue), type cmd, and hit Enter. A black window pops up already sitting in the right folder. (On Windows 11 you can also just right-click empty space inside the folder and pick Open in Terminal, same result.)

    To check Java installed properly, type java -version in that window and press Enter. You should see a version number pop up. If it says something like "not recognized" instead, restart your computer and try again, that usually fixes it.

    Using macOS or Linux instead?

    macOS: open Terminal (Applications, then Utilities, then Terminal), type cd followed by a space, then drag the unzipped folder into the Terminal window and press Enter.

    Linux: most file managers have an Open Terminal Here option when you right-click inside the folder. Otherwise just cd to it yourself.

  4. Build it. Still in that same terminal window, run:
    gradlew shadowJar

    On macOS or Linux it's ./gradlew shadowJar instead. The first build downloads Gradle and the RuneLite client, so give it a few minutes. It can look stuck, but it's working. After that, builds only take seconds.

  5. Run it. Same terminal window again:
    java -jar build/libs/{{ plugin_jar_name }}

    RuneLite opens with the plugin already loaded. Look for OSRS Toolkit Sync in the plugin list, no hub install needed. If your filename looks different, just check what's actually sitting in build/libs.

This starts its own copy of RuneLite.

It doesn't add the plugin to a RuneLite you already have installed. Only the Plugin Hub can do that, which is what the submission is for. Until then, just launch the game through the command above whenever you want the plugin running.

Updating it later

Download the ZIP again (or git pull in that folder), run the build command once more, and run the jar. Your settings and your journal are untouched by a rebuild.

If you play on a Jagex account, one more step

If you log in through the separate Jagex Launcher app instead of typing a username and password straight into RuneLite, this part's for you. If not, skip ahead.

The Jagex Launcher normally hands RuneLite your login for you. A client started from the command line misses out on that, so you'd land on the old username-and-password screen with no way through. Luckily RuneLite has a supported way around it: you tell the launcher to write your credentials to a file, and any RuneLite on that machine can read it. These steps come straight from RuneLite's own Using Jagex Accounts guide.

  1. Check your RuneLite launcher is 2.6.3 or newer. That's the launcher, not the client itself. Older launchers can't do this.
  2. Open the launcher's configuration. On Windows that is RuneLite (configure) in the Start menu. On macOS, run /Applications/RuneLite.app/Contents/MacOS/RuneLite --configure; on Linux, pass --configure to the launcher the same way.
  3. Add the flag. In the Client arguments box put:
    --insecure-write-credentials
    Save, and close the configuration window.
  4. Launch RuneLite through the Jagex Launcher once, the way you normally play. It writes your credentials to .runelite/credentials.properties.
  5. Now run the jar the same way as before (the "Run it" step above). It reads that file and signs in as your Jagex account, plugin and all.
That file is a login bypass, so treat it like a password.

Anyone holding credentials.properties can sign into your account without knowing your password, which is why the flag has "insecure" in its name. Don't share it, and keep it out of screenshots and support posts.

When you're done, delete the file and take --insecure-write-credentials back out of the launcher's client arguments, or it gets written again on every launch. If you think anyone else has seen the file, use End sessions in your account settings on runescape.com to invalidate it.

Turn it on

  1. Get a token. {% if account %}On your profile, press Get a token and copy it.{% else %}Sign in here first, then on your profile press Get a token and copy it.{% endif %}
  2. Open the plugin's settings in RuneLite. Click the wrench icon, then find OSRS Toolkit Sync.
  3. Paste the token into Pairing token, under Connection. The plugin will answer in the chatbox: green if the token was accepted, red with what to do if it wasn't.
  4. Switch on "Send to OSRS Toolkit Sync". That's the master switch. Nothing gets sent before it's on.
  5. Pick what to record. Under What to record you'll find Grand Exchange fills, player trades, gear and bank for PvM Readiness, valuable loot, and deaths. Leave off whatever you don't want tracked.

Play, and your fills will show up under RuneLite Activity, with positions opening on the Dashboard. For PvM Readiness, switch on the gear and bank option, then open your bank in game once. That's when the snapshot gets taken.

If nothing arrives

  • Your Dashboard says Idle when the token is saved but nothing's being sent. Either RuneLite's closed, or the master switch is off.
  • The plugin says in the chatbox whether a pairing token was accepted, right when you paste it in.
  • Events are not lost when the service is unreachable. They queue in .runelite/osrs-toolkit/events and go out when it is back.
