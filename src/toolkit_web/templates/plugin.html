Build it yourself

  1. Install Java 11 or newer. If you are not sure you have it, get Temurin — the default options are fine.
    2. {# Every link here is built from PLUGIN_BRANCH rather than written out, so the ZIP, the clone and the folder name cannot drift apart -- see the note beside that constant for the time they did, and what it cost. #}
  2. Download the plugin. Download the ZIP and unzip it — that gives you a folder called osrs-toolkit-runelite-{{ plugin_branch }}. With git instead:
    git clone {{ plugin_repo_url }}.git

    Browse the source first if you would rather see what you are building.

  3. Build it. Open a terminal in that folder and run:
    gradlew shadowJar

    On macOS or Linux it is ./gradlew shadowJar. The first build downloads Gradle and the RuneLite client, so give it a few minutes; later ones take seconds.

  4. Run it.
    java -jar build/libs/{{ plugin_jar_name }}

    RuneLite opens with the plugin already loaded — OSRS Toolkit Sync is in the plugin list, no hub install needed. Check build/libs if your filename differs.

This starts its own copy of RuneLite.

It does not add the plugin to a RuneLite you already have installed — only the Plugin Hub can do that, which is what the submission is for. Until then, launch the game through the command above when you want the plugin running.

Updating it later

Download the ZIP again (or git pull in that folder), run the build command once more, and run the jar. Your settings and your journal are untouched by a rebuild.

If you play on a Jagex account

The Jagex Launcher hands RuneLite your login, and a client started from the command line does not get it — you would land on the old username-and-password screen with no way through. RuneLite has a supported way around this: tell the launcher to write its credentials to a file, which any RuneLite on that machine can then read. These steps are from RuneLite's own Using Jagex Accounts guide.

  1. Check your RuneLite launcher is 2.6.3 or newer. The launcher, not the client — older ones cannot do this.
  2. Open the launcher's configuration. On Windows that is RuneLite (configure) in the Start menu. On macOS, run /Applications/RuneLite.app/Contents/MacOS/RuneLite --configure; on Linux, pass --configure to the launcher the same way.
  3. Add the flag. In the Client arguments box put:
    --insecure-write-credentials
    Save, and close the configuration window.
  4. Launch RuneLite through the Jagex Launcher once, the way you normally play. It writes your credentials to .runelite/credentials.properties.
  5. Now run the jar from step 4 above. It reads that file and signs in as your Jagex account, plugin and all.
That file is a login bypass — treat it like a password.

Anyone holding credentials.properties can sign into your account without knowing your password, which is why the flag has "insecure" in its name. Do not share it, and keep it out of screenshots and support posts.

When you are done, delete the file and take --insecure-write-credentials back out of the launcher's client arguments, or it is written again on every launch. If you think the file has been seen by anyone else, use End sessions in your account settings on runescape.com to invalidate it.

Turn it on

  1. Get a token. {% if account %}On your profile, press Get a token and copy it.{% else %}Sign in here first, then on your profile press Get a token and copy it.{% endif %}
  2. Open the plugin's settings in RuneLite — the wrench icon, then OSRS Toolkit Sync.
  3. Paste the token into Pairing token, under Connection. Leave Service address alone; it already points here.
  4. Switch on "Send to OSRS Toolkit Sync". That is the master switch — nothing is sent before it.
  5. Pick what to record. Under What to record: Grand Exchange fills, player trades, gear and bank for PvM Readiness, valuable loot, deaths. All of them are yours to leave off.

Play, and your fills appear under RuneLite Activity with positions opening on the Dashboard. For PvM Readiness, switch on the gear and bank option and then open your bank in game once — that is when the snapshot is taken.

If nothing arrives

  • Your Dashboard says Idle when the token is saved but nothing is being sent — RuneLite closed, or the master switch off.
  • The plugin can draw a connection overlay in game: turn on Show connection status overlay to see what it thinks is happening.
  • Events are not lost when the service is unreachable. They queue in .runelite/osrs-toolkit/events and go out when it is back.
